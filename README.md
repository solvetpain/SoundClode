# SoundClode

<p align="center">
  <b>Минималистичный монохромный веб- и десктоп-клиент для SoundCloud</b>
  <br>
  <i>Быстрый, чистый звук без рекламы, элегантный чёрно-белый интерфейс и глубокая интеграция с Windows.</i>
</p>

---

## Основные возможности

- **Чистый звук без рекламы**: Воспроизведение треков напрямую через официальный API SoundCloud. Встроенный HLS-движок (`hls.js`) обходит региональные ограничения и ограничения DRM/превью, гарантируя непрерывное воспроизведение.
- **Pure B&W Монохром**: Лаконичный контрастный дизайн без раздражающих и кислотных цветов. Плавные 60 FPS анимации с аппаратным ускорением (`cubic-bezier`).
- **Эстетичная типографика**: Фирменный шрифт **PT Serif Caption** для заголовков, навигации и карточек. Возможность переключения на системный или Unbounded в настройках.
- **Discord Rich Presence**: Автоматическая трансляция текущего трека, автора, обложки и прогресса воспроизведения прямо в статус Discord.
- **Авторизация через соцсети**: Вход через Google, Apple или SoundCloud с поддержкой синхронизации лайков в реальном времени.
- **Полноценные профили артистов**:
  - Быстрый переход на страницу любого музыканта по клику.
  - Вкладки: **Popular tracks**, **Tracks**, **Albums**, **Playlists**, **Reposts**.
  - Кнопка «Слушать все» и ссылки на официальные страницы.
- **Feed и умные подписки**:
  - Горизонтальная карусель отслеживаемых исполнителей с аватарками.
  - Лента свежих релизов и новинок от авторов, на которых вы подписаны.
- **Интерактивная волна (Waveform Visualizer)**:
  - Точная визуализация формы аудиоволны на HTML5 Canvas.
  - Мгновенная перемотка трека кликом в любую точку волны.
  - Несколько режимов отображения (столбики, тонкие линии, базовая линия).
- **Нативное Windows-приложение (WPF + WebView2)**:
  - Безрамочное окно с плавной тенью и аккуратной кастомной панелью управления.
  - Встроенный обратный прокси для прозрачного обхода CORS-ограничений API и обложек.
  - Векторная высокочёткая монохромная иконка приложения для панели задач (DIB 32-bit ARGB).
  - Глобальные горячие клавиши управления воспроизведением.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| <kbd>Space</kbd> | Воспроизведение / Пауза |
| <kbd>→</kbd> | Перемотка вперёд на 5 секунд |
| <kbd>←</kbd> | Перемотка назад на 5 секунд |
| <kbd>N</kbd> | Следующий трек |
| <kbd>P</kbd> | Предыдущий трек |
| <kbd>L</kbd> | Добавить в «Мне нравится» / Убрать лайк |
| <kbd>M</kbd> | Выключить / Включить звук (Mute) |
| <kbd>S</kbd> | Перемешать треки (Shuffle) |
| <kbd>R</kbd> | Режим повтора (Все / Один / Выкл) |

## Быстрый запуск

### Вариант 1. Скачать готовый релиз (Windows .exe)
Самый простой способ — скачать файл из официального раздела **[Releases](https://github.com/solvetpain/SoundClode/releases/latest)**:
- **[SoundClode.exe](https://github.com/solvetpain/SoundClode/releases/download/v1.0.0/SoundClode.exe)** (Прямой запуск .exe без распаковки архива, портативный)
- **[SoundClode-v1.0.0-Windows-x64.zip](https://github.com/solvetpain/SoundClode/releases/download/v1.0.0/SoundClode-v1.0.0-Windows-x64.zip)** (Полный портативный ZIP-пакет со всеми библиотеками)
- **[SoundClode-SingleFile-v1.0.0.zip](https://github.com/solvetpain/SoundClode/releases/download/v1.0.0/SoundClode-SingleFile-v1.0.0.zip)** (Компактный портативный архив)

Скачайте **`SoundClode.exe`** и запустите! Никаких зависимостей или установки .NET не требуется.

### Вариант 2. Веб-версия (любой браузер)
Просто откройте файл `index.html` (или `SoundClode.html`) в любом современном браузере:
- Не требует установки серверов или зависимостей.
- Работает полностью автономно на клиентской стороне.

### Вариант 3. Сборка из исходников

**Требования:**
- Windows 10/11
- [.NET 6.0 SDK](https://dotnet.microsoft.com/download/dotnet/6.0)

**Сборка:**
1. Запустите скрипт `build.bat`.
2. Готовый исполняемый файл будет скомпилирован в папке `publish\SoundClode.exe`.

## Настройки и кастомизация

В приложении доступна боковая панель настроек (иконка шестерёнки в шапке):
- **Язык меню**: Русский или English.
- **Шрифт заголовков**: PT Serif Caption, Instrument Sans, Unbounded или системный шрифт.
- **Скругление углов**: Мягкие (20px), Круглые (34px), Острые (0px).
- **Стиль волны трека**: Столбики, тонкие линии или заливка снизу.
- **Автоплей и горячие клавиши**: Удобное управление воспроизведением.

---

## Стек технологий

- **Frontend**: Vanilla JavaScript (ES6+), HTML5 Canvas, HLS.js, CSS Custom Properties (CSS Variables).
- **Backend/Native Shell**: C#, WPF (.NET 6), Microsoft.Web.WebView2.
- **Интеграции**: Discord RPC (Rich Presence Named Pipe IPC).
- **API**: SoundCloud Public API v2 + HLS Stream Demuxing.
